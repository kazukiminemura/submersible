# ABYSSAL SCOUT

潜水艇で深海を自由に探索し、5つの生体サンプルを回収する短編3Dゲームです。

## 遊び方

1. `npm install`
2. `npm run start`
3. 表示されたローカルURLをブラウザで開きます。

WASD / 矢印キーで進行と旋回、Space で浮上、Shift で潜航、E で近くの青いビーコンを回収します。
V キーで正面の観察視点と通常の追従視点を切り替えます。
R キーまたはレーダー下のボタンでソナーを発信します（8秒で再充電）。レーダーは艇の前方を上にして、35 m以内の未回収サンプルを表示します。サンプル回収で200点、生物の初発見で50点を獲得します。

探査開始時に、Web Audioで作曲したオリジナルの探索BGM「DEEP BLUE」（72 BPM）が再生されます。ソナー・回収・生物発見・ミッション終了には効果音が付きます。Mキーまたは右上のボタンで消音でき、音量と消音設定はブラウザに保存されます。別タブへ移動すると音声を休止します。音楽ファイルの外部配信や追加の音声ライブラリは使いません。
開始地点と探索ルートに、大イカ・大ダコ・巨大ガニ・発光する大型深海魚が各2体出現します。腕、脚、尾びれが動き、海中や海底をゆっくり移動します。
潜水艇は参考画像に合わせた銀白色の船体、大型観測ドーム、補強リング、外付け推進器を備え、2灯の前照灯には水中の光の筋を加えています。

## Blenderアセット

Blender 4.5.3 LTSで生成した詳細モデルを実際にゲームへ読み込んでいます。

- 編集用：`blender/abyssal_scout.blend`
- ゲーム用：`public/models/submersible.glb`
- 再生成：`blender --background --python blender/build_realistic.py`

海洋生物もBlenderで作成したモデルです。

- 編集用：`blender/marine_creatures.blend`（種類ごとのコレクション）
- ゲーム用：`public/models/creatures/` の `squid.glb`、`octopus.glb`、`crab.glb`、`angler.glb`
- 再生成：`blender --background --python blender/build_creatures.py`
- 色素斑・皮膚や甲殻の凹凸テクスチャをモデル内に格納。イカとタコの連続した腕と吸盤、カニの関節とはさみ、深海魚の口腔・針状の歯・膜状のひれを造形しています。
- 腕とひれはBlenderのシェイプキーをゲームで補間し、カニは脚の付け根を動かします。8体の間で形状とテクスチャを共有し、変形量は個別に保持します。全モデルの読み込み完了後に探査を開始できます。
- `node scripts/verify-creatures.mjs` でGLBの形状、腕の接続、埋め込みテクスチャ、変形データを検証できます。編集用Blenderファイルでは4種類を横に並べ、ゲーム用GLBはそれぞれ原点に配置して書き出します。

このPCではポータブル版が `.tools/blender-4.5.3-windows-x64/blender.exe` にあります（Git対象外）。モデル生成スクリプトは現在のBlenderシーンを消去するため、バックグラウンドの新規プロセスで実行してください。旧 `create_submersible.py` は初期試作です。

船体・観測窓・ボルト・補強リング・推進器・着底脚・マニピュレーターをBlenderで作成。ブラウザ側で砂の凹凸、海底地形、岩、サンゴ、浮遊物、前照灯を描画します。開始にはモデル読み込みの完了が必要です。サンプルは3 m以内で回収でき、エネルギー切れでも再出発できます。
